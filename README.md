# FlowTask — лабораторна робота №4–5

Статичний навчальний landing page: HTML, CSS і JavaScript. Виправлено accessibility, technical SEO та performance офіційного starter зі збереженням дизайну.

## Запуск у Windows / VS Code

Відкрити цю теку у VS Code. Встановити розширення **Live Server** (Ritwick Dey), натиснути правою кнопкою на `index.html` → **Open with Live Server**. Node.js та `npm install` не потрібні.

## Деплой

Vercel: Framework Preset **Other**, Root Directory — корінь цієї теки. Встановлення залежностей і збірка не потрібні, Output Directory — `.`. Для GitHub Pages оберіть гілку `flowtask-site`, папку `/ (root)` у Settings → Pages → Deploy from a branch.

Canonical: https://byebyeskiy.github.io/front-lab-4-5/ . Перевіряти robots.txt слід у корені Vercel origin; файл у підкаталозі GitHub Pages не є origin-level robots.txt.
